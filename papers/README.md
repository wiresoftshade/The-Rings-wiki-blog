## Terrain Rendering using Spherical Clipmaps

*Malte Clasen and Hans-Christian Hege.* [Original English *pdf*](Terrain_Rendering_using_Spherical_Clipmaps.pdf)

**Abstract**

We describe a terrain rendering algorithm for spherical terrains based on clipmaps. It leverages the high geometry
throughput of current GPU to render large static triangle sets. The vertices are displaced by a height map texture.
Our main contribution is mapping of texture coordinates to calculate the height map sample position based on the
static vertex offset and the variable view position.

**Аннотация**

Мы описываем алгоритм рендеринга сферических ландшафтов на основе карт отсечения. Он использует высокую геометрическую пропускную способность современных графических процессоров для рендеринга больших статических наборов треугольников. Вершины смещаются с помощью текстуры карты высот. Наш основной вклад заключается в сопоставлении текстурных координат с расчетом положения образца карты высот на основе статического смещения вершины и переменного положения точки обзора.
