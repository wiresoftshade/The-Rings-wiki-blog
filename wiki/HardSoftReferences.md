# Hard and Soft References

**Hard reference** — это прямая ссылка на ассет. Это указатели на `UObject` Он загрузится в память вместе с объектом, который на него ссылается. Без вариантов.

`UObject*`, `TSubclassOF<>`, `UStaticMesh*` in `UPROPERTY` — все это **hard rferences**.

**Цепочки зависимостей.** Загружаешь один bluepront — он тянет за собой мещи, текстуры, звуки и дочерние blueprints.

**Soft reference** — это строка `String`. Путь к ассету. Не загружается в память. Необходимо загрудить командой явно. Контролируешь момент загрузки сам. Теоретически строку Soft reference можно редактировать. Но компилятор заранее не скажет, если ссылка не верная. Это выразится только в рантайме. Ассет не загрузится. 

`TSoftObjectPtr<T>`, `TSoftClassPtr<T>`

```cpp
// soft reference - ничего нет в памяти
TSoftObjectPtr<UMaterial> Ref;

// явная загрузка
Streamable.RequestAsyncLoad(Ref; Callback);
```

## Hard vs Soft — Когда что использовать

Если объект не может существовать без какого либо ассета — помечаем как hard reference.

Если ассет может существовать и он используется иногда — можно пометить как soft reference.



| Use Hard                   | Use Soft                          |
| -------------------------- | --------------------------------- |
| Меши персонажа/меши оружия | Иконки инвентаря (200+ предметов) |
| Физические ассеты          | Боссы на других уровнях           |
| Звук выстрела в шутерах    | Скины и DLC контент               |
| Базовый враг на уровне     | Звук редкого крита                |
| **Ассет нужен всегда**     | **Ассет нужен редко**             |

## Ньюанс: DataTable — тихая бомба

Если в DataTable есть список из hard reference тогда при обращении к ней будут загружены все эти объекты в память. Может появиться спайк в рантайме. 

Лучше здесь использовать soft reference. Найти нужную строуи и загрузить элементы по soft reference. 

# Cast to... неявная hard reference

Решением может быть использование interfaces. Но если **объект** на который делается Cast to **уже загружен**, **Cast to — не проблема**.
