# Это прототип шейдерной функции. hlsl

*Она же есть в нодах материала в проекте*

Функция возвращает значение поля расстояний для гиперболической орбиты. `DistanceField`. На самом деле для любой орбиты. Это нужно для рендера тонкой линии на экране при любом угле обзора и дальности наблюдения. При помощи `DDX`, `DDY`. На входе ей нужно только что эксцентриситет `e` и фокальный параметр `p`. UV на модели represents нормалиированные локальные координаты орбиты.

```hlsl
float GetHyperbolaField(float2 uv, float e, float p)
{
    float orbit_term = p - e * uv.x;
    float is_valid = step(0.0001, orbit_term);
    return lerp(10000.0, length(uv) - orbit_term, is_valid);
}
```

А это прототип из нейросиетки. Ну, тут больше описаний что для чего работатет.

```hlsl
// 0.0 — точка строго на орбите.
// Положительное/отрицательное значение — отклонение от орбиты.
float GetHyperbolaField(float2 uv, float e, float p)
{
    // uv — это декартовы координаты (x, y) относительно фокуса орбиты (0,0)
    float x = uv.x;
    float y = uv.y;

    float r = length(uv); // Быстрое вычисление sqrt(x*x + y*y)
    
    // Вспомогательная линейная часть из уравнения конического сечения
    float orbit_term = p - e * x;

    // Функция step(a, b) возвращает 1.0, если b >= a, иначе 0.0.
    // Если orbit_term <= 0, то is_valid станет равным 0.0.
    float is_valid = step(0.0001, orbit_term);

    // Если область нефизическая (is_valid = 0), мы возвращаем огромное число (10000.0).
    // Если область правильная (is_valid = 1), возвращается честная разность.
    return lerp(10000.0, r - orbit_term, is_valid);

    // На практике собранный шейдер не потребовал отсеченея правой части гиперболы. 
}
```
