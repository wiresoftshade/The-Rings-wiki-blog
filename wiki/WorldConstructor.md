# World Constructor. Система построения окружения

Начинается все с интерфейса, куда игрок вводит параметры системы. Это гравитация планеты с большой массой, количество спутников, количество колец и их свойства. Свойства колец: а) баланс льда и силикатов, б) Степень их минерализации. Указываются станции на орбитах.

Так же игрок выбирает в какой мир играть: а) сгенерированный б) предустановленный в) полет вокруг одного из спутников

Последовательность действий системы. И назначение ее частей. Сначала `BP_GameInstance` создает менеджер экторов `BP_ActorManager`. Функция менеджера регистрировать, хранить и выдавать списки всех экторов созданной сцены. Далее `BP_GameModeBase` определяет будет ли строиться сцена по флагу `bCreateScene`. или использовать экторы на уровне по флагу `bGatherFromLevel`. По команде гейммода запускается создание сцены и/или сбор с уровня. GameInstance запускает создание основной планеты с большой массой, спутников, колец и станций. Передает эти экторы менеджеру для регистрации. Так мы всегда можем получить доступ к основной планете и к ее спутникам. Так же к каждому из колец, станций кораблям и роверам.

## Какие объекты включает в себя система

### Структуры

<!-- comment -->

- **S_RingProperty** - Состав. Установки спада плотности по краям. Рандомизация по высоте. Скорость вращения. Количество трэков и кластеров в них. Радиусы начала и конца, а также начальный радиус всех колец. Координаты общей текстуры колец для мапинга данного кольца, а так же координата Vcoord. Возможно понадобится для изображения изменений в кольце. TextureData - устарел.
- **S_TrackProperty** - формируется после `Setup Grid` Там: индекс трека, разметка UV данного трека. А так же параметры для создания Семплов полей - это состав веществ, разделенный на конкретный перечень. Массив `Fields` - это поля для каждого трека. Все это используется для создания семплов полей.
- **S_ClusterProperty** - Идентичен свойствам трека. Сюда они и попадают из свойст трека. `Ring` передает эти данные кластеру `SetupRingField`. `Cluster` не рассчитывается самостоятельно. Берет расчет инстансов из семплов полей по `Key` 
- **S_SpaceBodyProperty** - данные о космическом теле. Класс, Имя, Radius. Применяется в генерации этих параметров для каждого тела созданного генератором. 
- **S_WorldConstructorData** - установленные пользователем данные из интерфейса свойств мира. `InitialSeed` - главный параметр рандомизации всего мира. Генерируется для каждого рандомного мира. Считывается из пресета, при выборе дефолтного мира. Остальные параметры тел, станций, колец тоже либо генерируются, либо считываются с пресетов. 

### Дата ассеты. Типы сеттингов

- **PDA_WorldSettings** - Содержит SEED мира. Содержит количество всех тел, станций, кораблей, роверов, колец в мире. Это структура `S_WorldConstructorData`. Так же массив со списком типов колец (`PDA_Ring`). 
    - Дебаг-флаги: 
    - `SpawnSpaceshipIntoRing`
    - `SpawnableAsteroids`/`AllowSpawnAsteroids`
    - `DebugPreviewClusters`
    - `DebugVisualising Updating as Dots on Screen`
    - и др.
- **PDA_PerformanceSettings** - установка глобальных сеттингов производительности. Размеры кластеров. Мистанция создания кластеров. Максимум инстансов астероидов. Максимальная и минимальная плотность. 
- **PDA_Ring** - Описывает свойства кольца. Его состав и плотность, в том числе какие поля оно может содержать.
- **PDA_Field** - Описывает свойства поля. Его тип, его состав и плотность, в том числе какие типы астероидов может содержать. Материал по-умолчанию, если не определен в астероиде.
- **PDA_SingleAsteroid** - Определяет свойства астероида. Отдельный астероид тоже может содержать разные материалы. Имеет набор вариантов мешей и вариантов материалов. Настройки рандомизации. Единичные астероиды могут быть "облеплены" малыми камнями. Их параметры так же находятся здесь. Тут же должны находиться настройки для FX-ов столкновений. 


### Дата ассеты. Сеттинги

- **DA_DefaultWorldSettings** - Настройки мира, которые должны стартовать в начале каждой сесии и сетапиться в интерфейс WorldSettings. Это единый дата ассет для определения параметров мира. Предполагается создавать любое количество таких дата ассетов, определять в них настройки миров.

- **DA_Ring_Ice / DA_Ring_Sislicates / DA_Ring_Mix** - примерные пресеты колец.
- **DA_Field_Ice / DA_Field_Sislicates / DA_Field_PureMineral** - основные типы полей, создаваемые конструктором.
- **DA_Asteroid...** - так именуются типы астероидов. Набор сейчас достаточно большой:
    - DA_Asteroid_**Gemstones** - угловытый камушек. Гигантское количество вариантов. + описаны настройки микрокамушков.
    - DA_Asteroid_**Gravel** - гладенький камушек. + описаны настройки микрокамушков.
    - DA_Asteroid_**IceCrystal** - ледяной материал, кристалический камушек. + описаны настройки микрокамушков.
    - DA_Asteroid_**IceGravel** - ледяной материал, гладенький камушек. + описаны настройки микрокамушков.
    - DA_Asteroid_**Legacy** - это самый первый астероид красивый с кратерами. + описаны настройки микрокамушков.
    - DA_Asteroid_**Meteors** - здоровенный камень Meteorite с имитацией кратеров.  + описаны настройки микрокамушков.
    - DA_Asteroid_**PureMineral** - набор из гладеньких и острых камушков с двумя вариантами минеральных материалов. + описаны настройки микрокамушков.


### Menu widget

- кнопка **World Constructor** которая запускает настройками мира, 
где можно создать до 27 колец, луны и станции, латающие вокруг. (Виджет `W_WorldSettings`).
- кнопка **Ala Saturn world**, которая загрузит предустановленный уровень с газовым гигантом и кольцами, напоминающими Сатурн. 
- кнопка, **Fly around Moon** которая загрузит предустановленный уровень с полетом вокруг луны с миром мультящных шахмат.
- кнопка, **Drive Rover on Moon** которая запустит предустановленный уровень с ровером. Можно ездить по луне, "пинать" камни или вылететь в космос навечно.

### **World Settings widget**

Настраиваются параметры:
- Moon bodies
    - ползунок. количество лун. он создаст примерно порядка 10, 20, 30. Но сколько точно вы не знаете.
- Big Mass body
    - ползунок. гравитационная постоянная тела. это по сути сила гравитации. А определит она в итоге скорость игры.
    - установить радиус тела.
- Ring map settings
    - список колец. можно увеличить/уменьшить количество. при добавлении создаются рандомные параметры кольца.
    - ползунок. пустое расстояние между этим и соседним.
    - ползунок. ширина кольца.
    - ползунок. минерализация в процентах.
    - ползунок. Содержание в виде баланса между льдом и силикатами.
- Orbit Stations
    - Список типов станций-спутников. можно добавить и удалить тип. (Орбиты проходят только в щелях между кольцами. А так же внутри или снаружи колец.)
    - количество станций. он создаст примерно порядка 10, 20, 30. Но сколько точно вы не знаете.

### **Game Instance**

- **EventInit** создает Actor Manager и сетапит его.
- **StartWorld** запускает пустой уровень.
- **GatherFromLevel** - собирает с левела заготовленные кольца, bigmass body, спутники, станции, и тд.
- **CreateScene** Создает сцену, по данным конструктора.

Создание и сборка идентичны после. Они обе передают менеджеру зарегистрировать экторы. Далее запускают по порядку всех. Обновляет на планете тени от кольца.

Набор функций BP_GameInstance, которые занимаются генерацией объектов мира. 
Создает в заданном порядке:
- **CreateEnvironment** создает свет звезды, свет окружения, создает окружение звезд.
- **CreateBigMassBody** создает главную планету с большой массой (флаг `King`).
- **CreateBodies**  создает спутники этой планеты.
- **CreateRings** создает кольца. (Кольцу передает нужную полноту списка данных)
- **CreateSpaceStation** создает космические станции.
- **CreateSpaceship** создает корабль игрока.
- генерирует Render Target Assets: `RT_RingBaseData` - для параметров кольца, `RT_RingOpticData` - для оптических свойств кольца. Эти текстуры в кольцах будут использоваться для рендеринга и для генерации параметров.

Функции для создания шаблонов кластеров колец
- **MakeTransformsToDictionary** - создает шаблон трансформов, ключ и кладет в словарь. запускается по запросу `BP_Ring` 
- **GetTransformsFromDictionary** - запускается по запросу `BP_Ring`. Выдает по ключу шаблон трансформов. 

### **Actor Manager**
- **Registrate**: регистрирует каждый эктор, чтобы предоставлять их другим системам по запросу.
    - спутники `BaseSpaceBodies`, `Moons`.
    - кольца `Ring` and `FarRing`.
    - корабли игрока `SpaceShips`, `Rovers` и `SpaceStations`.
    - экторы освещения и окружения `SpaceLight`, `StarfieldSpaceSphere`.
- **RegistrateBigMassBody** - регистрирует главную планету `BigMassBody`.
- **StartRings** инициирует запуск колец. Кольца запускаются по порядку, начиная с первого. Они делают пул кластеров последовательно. 
- **StartSpaceBody** инициирует запуск тел.
- **StartSpaceStation** инициирует запуск станций.
- **StartSpaceShip** инициирует запуск систем корабля игрока.
- **StartRover** - инициирует запуск систем ровера.
- **StartAsteroids** - инициирует запуск отдельных астероидов.
- **StartAllActorsStepByStep** - служит для запуска в правильной последовательности всех Экторов. На старте левела запускается после создания левела или после сборки с готового.
- **OnRingPoolReady** - вспомогательная функция для последовательного пула кластеров.
- Набор функций **Get...** - чтобы получить тот или иной зарегистрированный Actor. Есть возможнось, например, взять одно кольцо по индексу (**GetRing**), есть возможность взять все кольца (**GetRings**). Возможны дополнения. 
- Набор функций **GetNumberOf...** - чтобы получить просто количество экторов определенного типа (**GetNumberOfRovers**). 
- **GetStarLight**  выдает `DirectionalLightComponent` светильника звезды.
- **GetSpaceLight** выдает освещение космоса - `BP_SpaceLight`.
- **GetStarfieldSpaceSphere** выдает окружение космоса - `BP_StarfieldSpaceSphere`.

### **Function Library Main** (FL_Main)
- **GetActorManager** - выдает эктор менеджер.
- **RenderRingDataTexturesFromStream** - рандомно выбирает текстуры 1 - для параметров кольца, 2 - для оптических свойств кольца. Рендерит их в Render Targets `RT_RingBaseData`, `RT_RingOpticData`. 
- **RenderRingShadowTexture** - создает текстуру тени колец на планете. использует созданную ранеее RingDataTexture.
- **SolveCluster** - нужен для расчета семпла кластера. это предварительный расчет количества инстансов и In fact randomize position.
- **GetRandomIceBalance** - позволяет создать параметр Ice Balance особым рандомным образом.
- **GetRandomMinerals** - позволяет создать параметр Minerals особым рандомным образом.
- **MakeDataKey** - создает ключ для генерации семпла трека.
- **GetPerformanceSettings** - дает установки быстродействия. используется в кольцах, кластерах. Позволяет в реальном времени их менять.
- **GetWorldDefaultSettings** - дает установки дефолтного мира. так же там есть раздел debug флагов. Позволяет в реальном времени их менять.

### Несколько **Game Modes** 

Для каждого уровня **настроен гейммод**, который командует собирать с уровня либо строить его.

- **GameMode_MainAllRings** - для предустановленного левела, 
- **GameMode_Rover** для уровня с ровером на луне. 
- **GameMode_AroundPlanet**- для полета вокруг луны, 
- **GameMode_EmptyLevel** - для пустого уровня конструктора. 
- **GameMode_Menu** для уровня с главным меню. 
 
Так же есть другие:

- **GameMode_Mouse** - был сделан для тестов. можно просто летать по миру.
- **GameMode_Flying** - базовый для полетов на корабле. Спавнит корабль и дает им управлять. 
- **GameMode_Base** - родительский гейммод. Главная логика с выбором построить уровень или собрать с уровня.

### **SpaceLight**
- освещает сцену директлайтом и скайлайтом.

### **Starfield Space Sphere**
- **ConstructionScript** создает сферу с текстурой, создает изображения звезд, создает изображение звезды системы, *которая светит на сцену при помощи* `SpaceLight`.

## Кольца - объекты подчиняющиеся системе

Кольца только используют данные из конструктора в строительстве и визуализации. Однако они вызывают функции конструктора из `BPGameInstance` для создания шаблонов.
