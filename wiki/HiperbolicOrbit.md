# Точка на гиперболической орбите зависит от времени. Реализация метода на c++

Для вычисления положения точки на гиперболической орбите в зависимости от времени необходимо решить **уравнение Кеплера для гиперболического движения**:

$$M=e\sinh H-H$$

Где:

- $M$ — средняя аномалия (пропорциональна времени $t$).

- $e$ — эксцентриситет орбиты ($e > 1$).

- $H$ — гиперболическая эксцентрическая аномалия.

Ниже представлена эффективная реализация на C++ с использованием метода Ньютона-Рафсона для численного решения уравнения.

```cpp
#include <iostream>
#include <cmath>
#include <limits>

// Структура для хранения координат точки на плоскости орбиты
struct OrbitPoint {
    double x;
    double y;
};

/**
 * Вычисляет положение точки на гиперболической орбите.
 * 
 * @param t Время от момента прохождения перицентра (в секундах)
 * @param mu Гравитационный параметр центрального тела (м^3 / с^2)
 * @param a Большая полуось орбиты (для гиперболы берется положительной)
 * @param e Эксцентриситет орбиты (e > 1)
 * @return Структура OrbitPoint с координатами X и Y в плоскости орбиты
 */
OrbitPoint getHyperbolicPosition(double t, double mu, double a, double e) {
    // 1. Вычисление среднего движения (n) и средней аномалии (M)
    double n = std::sqrt(mu / std::pow(a, 3));
    double M = n * t;

    // 2. Решение уравнения Кеплера методом Ньютона-Рафсона (e * sinh(H) - H = M)
    // Начальное приближение для H
    double H = (M > 0) ? std::log(2 * M / e + 1) : -std::log(-2 * M / e + 1); 
    
    const int MAX_ITERATIONS = 100;
    const double TOLERANCE = 1e-12;

    for (int i = 0; i < MAX_ITERATIONS; ++i) {
        double f = e * std::sinh(H) - H - M;
        double df = e * std::cosh(H) - 1.0;
        
        double delta = f / df;
        H -= delta;

        if (std::abs(delta) < TOLERANCE) {
            break;
        }
    }

    // 3. Вычисление координат X и Y в перифокальной системе координат
    // (ось X направлена на перицентр)
    double x = a * (e - std::cosh(H));
    double y = a * std::sqrt(e * e - 1.0) * std::sinh(H);

    return {x, y};
}

int main() {
    // Пример: спутник около Земли
    double mu = 3.986004418e14; // Гравитационный параметр Земли (м^3/с^2)
    double a = 7000000.0;       // Большая полуось (7000 км)
    double e = 1.4;             // Эксцентриситет (гипербола)
    double t = 3600.0;          // Время через 1 час после перицентра (секунды)

    OrbitPoint pos = getHyperbolicPosition(t, mu, a, e);

    std::cout << "Положение точки через " << t << " секунд:" << std::endl;
    std::cout << "X: " << pos.x / 1000.0 << " км" << std::endl;
    std::cout << "Y: " << pos.y / 1000.0 << " км" << std::endl;

    return 0;
}
```

Используйте код с осторожностью.

## Важные нюансы реализации

- **Начальное приближение ($H_{0}$)**: Функция $\sinh(H)$ растет экспоненциально. Использование простой линейной инициализации ($H_0 = M$) приведет к переполнению double или долгой сходимости. Представленная логарифмическая аппроксимация обеспечивает сходимость метода Ньютона за 4–7 итераций.

- **Знак $a$**: В астродинамике большую полуось гиперболы часто берут отрицательной ($a < 0$). В данном коде для простоты формул `a` передается как **абсолютное (положительное)** значение.

- **Ориентация осей:** Координаты $X$ и $Y$ рассчитываются в плоскости орбиты, где ось $X$ совпадает с линией апсид (направлена на перицентр), а начало координат находится в **фокусе** (центре притягивающего тела).

Перевод векторов состояния (положение $\vec{r}$ и скорость $\vec{v}$) в кеплеровы элементы орбиты выполняется через классические интегралы движения.

Ниже представлена эффективная и устойчивая реализация метода на C++, которая корректно обрабатывает все типы орбит: эллиптические, параболические и гиперболические.

```cpp
#include <iostream>
#include <cmath>
#include <algorithm>

// Структура для трехмерного вектора
struct Vector3D {
    double x, y, z;

    // Векторные операции
    double length() const { return std::sqrt(x*x + y*y + z*z); }
    double dot(const Vector3D& v) const { return x*v.x + y*v.y + z*v.z; }
    Vector3D cross(const Vector3D& v) const {
        return { y*v.z - z*v.y, z*v.x - x*v.z, x*v.y - y*v.x };
    }
};

// Структура для Кеплеровых элементов орбиты
struct KeplerianElements {
    double a;      // Большая полуось (м)
    double e;      // Эксцентриситет
    double i;      // Наклонение (радианы)
    double Omega;  // Долгота восходящего узла (радианы)
    double omega;  // Аргумент перицентра (радианы)
    double nu;     // Истинная аномалия (радианы)
};

/**
 * Конвертирует векторы состояния в Кеплеровы элементы орбиты.
 * 
 * @param r Радиус-вектор положения (м)
 * @param v Вектор скорости (м/с)
 * @param mu Гравитационный параметр центрального тела (м^3 / с^2)
 * @return Структура KeplerianElements с параметрами орбиты
 */
KeplerianElements stateVectorsToKepler(const Vector3D& r, const Vector3D& v, double mu) {
    const double EPS = 1e-11; // Малая величина для избежания деления на 0
    KeplerianElements kepler{};

    double r_mag = r.length();
    double v_mag = v.length();

    // 1. Удельный угловой момент (h = r x v)
    Vector3D h = r.cross(v);
    double h_mag = h.length();

    // 2. Вектор восходящего узла (n = k x h)
    Vector3D n = { -h.y, h.x, 0.0 };
    double n_mag = n.length();

    // 3. Вектор эксцентриситета (e = ((v^2 - mu/r)*r - (r*v)*v) / mu)
    double v_sq = v_mag * v_mag;
    double r_dot_v = r.dot(v);
    Vector3D e_vec = {
        ((v_sq - mu / r_mag) * r.x - r_dot_v * v.x) / mu,
        ((v_sq - mu / r_mag) * r.y - r_dot_v * v.y) / mu,
        ((v_sq - mu / r_mag) * r.z - r_dot_v * v.z) / mu
    };
    kepler.e = e_vec.length();

    // 4. Большая полуось (a) через удельную энергию (epsilon)
    double epsilon = (v_sq / 2.0) - (mu / r_mag);
    if (std::abs(kepler.e - 1.0) > EPS) {
        kepler.a = -mu / (2.0 * epsilon); // Для гиперболы 'a' будет отрицательной
    } else {
        kepler.a = std::numeric_limits<double>::infinity(); // Парабола
    }

    // 5. Наклонение орбиты (i)
    kepler.i = std::acos(std::clamp(h.z / h_mag, -1.0, 1.0));

    // 6. Долгота восходящего узла (Omega)
    if (n_mag > EPS) {
        kepler.Omega = std::acos(std::clamp(n.x / n_mag, -1.0, 1.0));
        if (n.y < 0.0) {
            kepler.Omega = 2.0 * M_PI - kepler.Omega;
        }
    } else {
        kepler.Omega = 0.0; // Экваториальная орбита
    }

    // 7. Аргумент перицентра (omega)
    if (n_mag > EPS) {
        if (kepler.e > EPS) {
            kepler.omega = std::acos(std::clamp(n.dot(e_vec) / (n_mag * kepler.e), -1.0, 1.0));
            if (e_vec.z < 0.0) {
                kepler.omega = 2.0 * M_PI - kepler.omega;
            }
        } else {
            kepler.omega = 0.0; // Круговая наклонная орбита
        }
    } else {
        // Экваториальная орбита: долгота перицентра вместо omega
        if (kepler.e > EPS) {
            kepler.omega = std::atan2(e_vec.y, e_vec.x);
            if (kepler.omega < 0.0) kepler.omega += 2.0 * M_PI;
        } else {
            kepler.omega = 0.0; // Круговая экваториальная орбита
        }
    }

    // 8. Истинная аномалия (nu)
    if (kepler.e > EPS) {
        kepler.nu = std::acos(std::clamp(e_vec.dot(r) / (kepler.e * r_mag), -1.0, 1.0));
        if (r_dot_v < 0.0) {
            kepler.nu = 2.0 * M_PI - kepler.nu;
        }
    } else {
        // Круговая орбита: аргумент широты вместо истинной аномалии
        if (n_mag > EPS) {
            kepler.nu = std::acos(std::clamp(n.dot(r) / (n_mag * r_mag), -1.0, 1.0));
            if (r.z < 0.0) kepler.nu = 2.0 * M_PI - kepler.nu;
        } else {
            kepler.nu = std::atan2(r.y, r.x);
            if (kepler.nu < 0.0) kepler.nu += 2.0 * M_PI;
        }
    }

    return kepler;
}

int main() {
    double mu = 3.986004418e14; // Гравитационный параметр Земли

    // Пример векторов для гиперболической орбиты
    Vector3D r = { -6524834.0,  6862374.0,  6404285.0 };
    Vector3D v = {  4906.0,     5314.0,     7219.0 };

    KeplerianElements elements = stateVectorsToKepler(r, v, mu);

    std::cout << "Кеплеровы элементы орбиты:" << std::endl;
    std::cout << "Большая полуось (a):     " << elements.a / 1000.0 << " км" << std::endl;
    std::cout << "Эксцентриситет (e):     " << elements.e << std::endl;
    std::cout << "Наклонение (i):          " << elements.i * 180.0 / M_PI << " град" << std::endl;
    std::cout << "Долгота узла (Omega):    " << elements.Omega * 180.0 / M_PI << " град" << std::endl;
    std::cout << "Арг. перицентра (omega): " << elements.omega * 180.0 / M_PI << " град" << std::endl;
    std::cout << "Истинная аномалия (nu):  " << elements.nu * 180.0 / M_PI << " град" << std::endl;

    return 0;
}
```

Используйте код с осторожностью.

## Разбор критических моментов

- **Использование `std::clamp`**: При делении проекций векторов из-за погрешностей `double` значение может стать `1.00000000001`. Функция `std::acos` вернет `NaN`. Ограничение диапазона в $[-1.0, 1.0]$ защищает от этого сбоя.

- **Знак Большой полуоси ($a$):** Обратите внимание, что алгоритм вычисляет $a$ через механическую энергию $\epsilon $. Для **гиперболы** энергия $\epsilon > 0$, поэтому $a$ получится **отрицательным** ($a < 0$). В предыдущем коде для расчета точки по времени использовался модуль этой величины.

- **Сингулярности (Особые случаи):**

    - **Если орбита экваториальная** ($i = 0$), вектор узлов $\vec{n}$ вырождается в ноль. Код перехватывает это условие и корректно пересчитывает долготы относительно оси $X$.
    - **Если орбита круговая** ($e = 0$), вектор эксцентриситета $\vec{e}$ вырождается. Истинная аномалия заменяется аргументом широты (угол от линии узлов).
