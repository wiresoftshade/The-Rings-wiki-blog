# Subsystems

Это Класс. Имеет свой жизненный цикл и свою область видимости (так называемый scope).

1. Engine Subsystem
2. World Subsystem
3. Local Player Subsystem
4. Editor Subsystem
5. Game Instance Subsystem

Использовать сабсистемы от Game Instance Subsystem для кошелька, статы игрока и подобного это удобно, потому как ее жизненный цикл будет пока игра запущена. В отличии от компоненты на игроке. Придется содержимое сохранять каждый Destroy игрока и каждый Spawn вновь загружать. Так же с этими данными можно работать в меню игры и в целом до запуска игрового уровня.
