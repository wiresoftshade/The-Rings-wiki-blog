# Пользовательская документация: BP_BaseSpaceBody

## 1. Введение

**BP_BaseSpaceBody** — это базовый блюпринт Unreal Engine 5, предназначенный для создания **космических тел** (планет, звёзд, спутников) в проекте «The Rings». Он реализует:

- Орбитальное движение по законам Кеплера (через отдельный компонент `KeplerOrbitAnimationComponent`).
- Гравитационное взаимодействие (притяжение игрового корабля).
- Визуализацию орбиты (плоскость, линия, узлы).
- Вывод информации о теле в пользовательский интерфейс (HUD).
- Синодическое вращение (поворот тела вокруг своей оси, синхронизированный с орбитой).

Класс спроектирован для гибкой настройки как через параметры в редакторе, так и программно через функции.

---

## 2. Структура блюпринта

### 2.1. Компоненты
- **StaticMeshComponent (или SphereComponent)** — основной визуальный компонент тела.
- **KeplerOrbitAnimationComponent** — C++‑компонент, отвечающий за расчёт кеплеровской орбиты (перемещение, скорость, параметры).
- **WidgetComponent** — компонент для отображения 3D‑виджета над телом (информационная панель).

### 2.2. Переменные (NewVariables)

Все переменные сгруппированы по категориям в деталях блюпринта.

#### Основные параметры тела
| Имя | Тип | Описание |
|-----|-----|----------|
| `BodyName` | Text | Отображаемое имя тела (например, «Земля»). |
| `BodyClass` | E_BodyClass (enum) | Класс тела (Звезда, Планета, Спутник, Астероид и т.д.). |
| `Standard Gravitational Parameter` | S_ExpNum (структура) | Гравитационный параметр **μ** (в м³/с²). Хранится как экспоненциальное число (мантисса + порядок). |

#### Орбитальные параметры
| Имя | Тип | Описание |
|-----|-----|----------|
| `BigMassBodyBSB` | BP_BaseSpaceBody | **Центральное тело**, вокруг которого движется данный объект (например, звезда). |
| `GravityForce` | bool | Включает гравитационное воздействие на игрока (притяжение). |
| `SpeedMultiplier` | double | Множитель орбитальной скорости. При **=1** — круговая орбита, при >1 или <1 — эллиптическая. |
| `Is Circular` | bool | Флаг, указывающий, что орбита круговая (используется для расчётов). |
| `Is Retrograde` | bool | Ретроградное движение (против направления вращения центрального тела). |
| `Is Equtorial` | bool | Экваториальная орбита (наклонение = 0). |
| `bOrbitIsVisible` | bool | Показывать визуализацию орбиты (линию и плоскость). |

#### Визуализация и ссылки
| Имя | Тип | Описание |
|-----|-----|----------|
| `OrbitPlane` | BP_OrbitPlaneDrawer | Актор, рисующий плоскость и линию орбиты. |
| `ReferencePlane` | Actor | Вспомогательный объект, отображающий опорную плоскость (например, эклиптику). |
| `ReferencePlaneDirection` | Vector | Вектор направления на точку весеннего равноденствия (используется для поворота опорной плоскости). |
| `SpaceBodyWidget` | W_SpaceBody (виджет) | Ссылка на виджет, отображающий информацию о теле (название, расстояние, скорость). |
| `BP Flying Pawn` | BP_FlyingPawn | Ссылка на игровой корабль (используется для расчёта расстояния до игрока). |

#### Вращение (синодическое)
| Имя | Тип | Описание |
|-----|-----|----------|
| `SynodicRotation` | bool | Включает вращение тела вокруг своей оси с учётом орбитального движения. |
| `Delta Rotation Z (Yaw)` | float | Угловая скорость вращения вокруг оси Z (в градусах за секунду). |

#### Отладочные и служебные
| Имя | Тип | Описание |
|-----|-----|----------|
| `UpdateOrbitTime` | double | Счётчик времени (используется для обновления орбиты). |
| `OnSpaceBodyStarted` | Delegate | Событие, вызываемое после полной инициализации тела. |

## 3. Основные функции (FunctionGraphs)

### 3.1. Получение информации

#### `Get Distance to Pown` → int
- Возвращает расстояние от тела до игрового Pawn в **сантиметрах** (целое число).
- Если Pawn недействителен, возвращает `-1`.

#### `GetSpeed` → double
- Возвращает текущую орбитальную скорость тела в **м/с** (с учётом множителя `SpeedMultiplier`).

#### `GetMovingDirection` → Vector
- Возвращает нормализованный вектор направления движения тела по орбите.

#### `GetRadius` → double
- Вычисляет радиус тела в **см** на основе дочернего компонента `NorthPoint` и масштаба актора.

#### `GetSpaceBodyProperty` → S_SpaceBodyProperty (структура)
- Возвращает структуру со свойствами тела: имя, класс, радиус (в см) и ускорение свободного падения на поверхности (в м/с²).

#### `GetBodyName` → Text
- Просто возвращает `BodyName`.

### 3.2. Управление параметрами

#### `SetRadius(Radius: int)`
- Устанавливает радиус тела: изменяет размер `SphereComponent` и перемещает `NorthPoint` на соответствующее расстояние.

#### `SetStandardGravitationalParameter(Standard Gravitational Parameter: S_ExpNum)`
- Устанавливает гравитационный параметр μ.

#### `SetBodyProperty(SpaceBodyProperty: S_SpaceBodyProperty)`
- Массово устанавливает свойства тела (имя, класс, радиус, μ) из структуры.

#### `SetOrbitVisibility(IsVisible: bool)`
- Включает/выключает видимость орбиты.

### 3.3. Орбитальное движение

#### `SetupKeplerOrbitAnimation()`
- **Ключевая функция.** Инициализирует компонент `KeplerOrbitAnimationComponent`.
- Определяет режим орбиты (`EOrbitMode`), который может быть:
  - **`ByStateVector`** — орбита рассчитывается из начальных вектора положения и скорости (в локальной системе опорной плоскости).
  - **`ByProperties`** — орбита задаётся через элементы (апоцентр, перицентр, наклонение и т.д.).
- При `ByStateVector` вычисляются векторы `L_R` и `L_V_Normalized` на основе относительного положения к центральному телу и скорости.
- При `ByProperties` используется фокальный параметр (радиус на узлах) и эксцентриситет для вычисления большой полуоси, апоцентра и перицентра.
- Все координаты переводятся из см в метры.

#### `UpdateLocation()`
- **Вызывается каждый кадр.** Обновляет позицию тела, используя текущие данные из `KeplerOrbitAnimationComponent` (вектор `RadiusAbsoluteLeftCS`).
- Преобразует координаты из локальной системы опорной плоскости в мировую через `GetReferencePlaneTransform`.
- Также вычисляет разницу положения между кадрами (`LocDelta`) и обновляет статистику (`LocDeltaMin`, `LocDeltaMax`) для отладки.

#### `UpdateOrbitAnimation()`
- Передаёт текущую истинную аномалию (`TrueAnomaly`) и её лаг в `BP_OrbitPlaneDrawer` для анимации линии орбиты.

#### `UpdateOrbitPlaneVisual()`
- Передаёт все необходимые параметры орбиты (векторы, размеры, углы) в `BP_OrbitPlaneDrawer` для отображения плоскости и линии.

#### `ConfigureOrbitDrawing()`
- Создаёт экземпляр `BP_OrbitPlaneDrawer` (если `BigMassBodyBSB` действителен) и связывает его с этим телом.

#### `ForceSetupOrbit()` (вызывается из редактора)
- Принудительно перезапускает настройку орбиты (полезно для отладки).

### 3.4. Взаимодействие с HUD

#### `SetupHUD()`
- Инициализирует виджет `W_SpaceBody` (находит компонент `Widget` и приводит его к нужному классу).
- Сохраняет ссылку в `SpaceBodyWidget`.

#### `UpdateWidgetStaticInfo()`
- Обновляет статическую информацию в виджете (название, класс тела).

#### `UpdateWidgetDynamicInfo()`
- Обновляет динамическую информацию: текущую скорость и расстояние до игрока.

### 3.5. События жизненного цикла

- **`ReceiveBeginPlay`** → вызывает `SetupHUD`.
- **`ReceiveTick`** → каждый кадр выполняет:
  - `UpdateLocation()` — движение по орбите.
  - Если `SynodicRotation` = true, добавляет вращение вокруг оси Z.
  - `UpdateOrbitAnimation()` и `UpdateOrbitPlaneVisual()` — обновление визуализации.
  - `UpdateWidgetDynamicInfo()` — обновление HUD.

## 5. Структуры данных

### `S_SpaceBodyProperty`
Содержит поля:
- `BodyName` (Text)
- `BodyClass` (E_BodyClass)
- `Radius(cm)` (int)
- `GravitationInRadius(m/s2)` (double) — ускорение на поверхности.

### `S_ExpNum`
Хранит число в экспоненциальной форме (для больших значений, например, гравитационных параметров).
- Предположительно содержит поля: мантисса и порядок (или целая и дробная части).

### `S_SpaceBodyInfo`
Используется для виджета — содержит имя и класс тела.

## 6. Использование в проекте

### Создание новой планеты
1. Создайте дочерний блюпринт от `BP_BaseSpaceBody`.
2. Установите необходимые параметры в деталях:
   - `BodyName`, `BodyClass`.
   - `Standard Gravitational Parameter` (μ) — можно взять из таблицы (Солнце: 1.32712440018×10²⁰).
   - `Radius` (через вызов `SetRadius` или вручную в конструкторе).
   - `BigMassBodyBSB` — укажите центральное тело (например, звезду).
   - Настройте орбитальные флаги (`Is Circular`, `Is Retrograde` и т.д.).
3. При необходимости переопределите `SetupKeplerOrbitAnimation` для задания начального состояния.

### Настройка визуализации
- Для отображения орбиты убедитесь, что `bOrbitIsVisible = true`.
- Если требуется изменить цвет или толщину линии, редактируйте `BP_OrbitPlaneDrawer`.

### Гравитация
- Установите `GravityForce = true`, чтобы тело притягивало игрока (нужна дополнительная логика в Pawn).

### Синодическое вращение
- Включите `SynodicRotation` и задайте `Delta Rotation Z (Yaw)` — например, 0.5 градусов/сек.

## 7. Зависимости и требования

- **Компонент `KeplerOrbitAnimationComponent`** — должен быть реализован в C++ (в проекте присутствует). Отвечает за расчёт орбиты по состоянию или элементам.
- **Структуры** `S_ExpNum`, `S_SpaceBodyProperty`, `S_SpaceBodyInfo` — определены в проекте.
- **Enum** `E_BodyClass` и `EOrbitMode`.
- **Blueprint-классы**:
  - `BP_OrbitPlaneDrawer` — рисовальщик орбиты.
  - `BP_ReferencePlane` — визуализация опорной плоскости.
  - `BP_FlyingPawn` — игровой корабль.
  - `W_SpaceBody` — виджет HUD.

---

## 8. Примечания

- Все внутренние расчёты ведутся в **метрах**, но визуальные компоненты используют **сантиметры** (перевод выполняется внутри функций).
- Для отладки предусмотрена функция `ForceSetupOrbit` (доступна в редакторе).
- Событие `OnSpaceBodyStarted` можно использовать для дополнительных действий после инициализации.

---

## 9. Заключение

`BP_BaseSpaceBody` — это гибкий и мощный базовый класс для космических симуляций. Он покрывает все основные аспекты: физику, визуализацию, взаимодействие с игроком и UI. Для добавления нового небесного тела достаточно унаследоваться от него и задать параметры, что делает его идеальным фундаментом для проекта «The Rings».
