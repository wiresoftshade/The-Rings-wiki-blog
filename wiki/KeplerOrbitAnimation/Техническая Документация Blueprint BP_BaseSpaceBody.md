# Документация Blueprint: `BP_BaseSpaceBody`

**Версия:** 1.0
**Дата:** 06.08.2026
**Назначение:** Базовый класс для всех интерактивных небесных тел в проекте "The Rings". Обеспечивает орбитальное движение, физические свойства, визуализацию и взаимодействие с пользовательским интерфейсом.

---

## 1. Общее описание

`BP_BaseSpaceBody` является фундаментальным строительным блоком для космической симуляции. Он представляет собой любой объект (звезду, планету, луну, астероид), который может существовать в игровом мире.

Blueprint инкапсулирует:
*   **Логику орбитального движения** на основе законов Кеплера.
*   **Физические характеристики** тела (радиус, масса/гравитационный параметр).
*   **Визуальное представление** (модель, сфера коллизий).
*   **Визуализацию орбиты** (отображение траектории).
*   **Интерфейс взаимодействия** (отображение информации на HUD/UI).

Blueprint предназначен для наследования и расширения для создания конкретных типов тел.

## 2. Зависимости и компоненты

| Компонент / Класс | Тип / Путь | Описание |
| :--- | :--- | :--- |
| **`BP_BaseSpaceBody`** | `Blueprint` | Данный класс. |
| **`Sphere`** | `SphereComponent` | Сфера коллизий и основа для визуального представления. Может использоваться для обнаружения столкновений и как родитель для визуальной модели. |
| **`KeplerOrbitAnimationComponent`** | `C++ Actor Component` (из `TheRings` модуля) | **Ядро орбитальной механики.** Выполняет все расчеты движения по орбите (на основе элементов Кеплера или вектора состояния). |

## 3. Публичные переменные

Это основные параметры, которые можно настраивать в инстансах (дочерних блюпринтах) для создания разных типов тел.

| Имя переменной | Тип | Описание |
| :--- | :--- | :--- |
| **`GravityForce`** | `bool` | Определяет, воздействует ли данное тело гравитацией на другие объекты. |
| **`BodyName`** | `Text` | Отображаемое имя небесного тела. |
| **`BodyClass`** | `E_BodyClass` (Enum) | Классификация тела (например, `Star`, `Planet`, `Moon`). Влияет на иконки и поведение. |
| **`Standard Gravitational Parameter`** | `S_ExpNum` (Struct) | Гравитационный параметр (μ) тела. Хранится как структура для удобного представления больших чисел. Используется в расчетах орбиты. |
| **`SynodicRotation`** | `bool` | Включает синодическое вращение (тело всегда повернуто одной стороной к центральному телу). |
| **`SpeedMultiplier`** | `double` | Множитель скорости анимации орбиты. Позволяет ускорять/замедлять орбитальное движение в реальном времени. |
| **`bOrbitIsVisible`** | `bool` | Управляет видимостью линии орбиты (через `BP_OrbitPlaneDrawer`). |
| **`Is Circular`** | `bool` | Указывает, является ли орбита круговой. Влияет на расчет начальных условий. |
| **`Is Retrograde`** | `bool` | Указывает, является ли орбита ретроградной (вращение в обратную сторону). |
| **`Is Equtorial`** | `bool` | Если `true`, орбита лежит в экваториальной плоскости центрального тела. |
| **`BigMassBodyBSB`** | `BP_BaseSpaceBody` (Объект) | **Ссылка на центральное тело**, вокруг которого вращается данный объект. От этого объекта берутся его трансформация (для построения опорной плоскости) и гравитационный параметр. |
| **`Initial...`** | `double` | Начальные орбитальные элементы (используются для настройки `KeplerOrbitAnimationComponent`). Например: `InitialArgumentOfPeriapsis`, `InitialLongitudeOfAscendingNode`, `InitialInclination`. |
| **`Radius`** | `int` | Радиус тела в сантиметрах. |
| **`Delta Rotation Z (Yaw)`** | `float` | Скорость вращения вокруг оси Z (для синодического вращения). |

## 4. Основные функции (Графы)

### 4.1. `UserConstructionScript`
*   **Вызывается:** В редакторе Unreal при размещении или изменении актора на сцене.
*   **Назначение:** Пустой по умолчанию. Используется для предварительной настройки визуальных элементов в редакторе.

### 4.2. `EventGraph` (Основной цикл выполнения)

#### `ReceiveBeginPlay` (Запуск игры)
*   **Вызывается:** Один раз при появлении актора в мире.
*   **Логика:**
    1.  Вызов функции `SetupHUD`. Это создает и связывает виджет с актором.

#### `ReceiveTick` (Каждый кадр)
*   **Вызывается:** Каждый кадр игры (пока актор активен).
*   **Логика:**
    1.  **Обновление позиции:** Вызов `UpdateLocation`. Рассчитывает новое положение актора на основе данных из `KeplerOrbitAnimationComponent` и перемещает его.
    2.  **Вращение:** Если `SynodicRotation` включена, то корневой компонент (`Sphere`) вращается по оси Yaw со скоростью `Delta Rotation Z (Yaw)`.
    3.  **Обновление UI:** Вызов `UpdateWidgetDynamicInfo` для обновления динамических данных на прикрепленном виджете.

### 4.3. Пользовательские функции (По назначению)

#### Основные функции орбитальной механики
*   **`SetupKeplerOrbitAnimation`**: Настраивает компонент `KeplerOrbitAnimationComponent`. В зависимости от режима (`OrbitMode`):
    *   **ByStateVector**: Инициализирует орбиту, используя начальный вектор положения (`L_R`) и скорости (`L_V_Normalized`).
    *   **ByProperties**: Инициализирует орбиту, используя орбитальные элементы (большая полуось, эксцентриситет, наклонение и т.д.).
*   **`UpdateLocation`**: Получает текущий радиус-вектор из `KeplerOrbitAnimationComponent`, преобразует его из локальной системы координат центрального тела (`BigMassBodyBSB`) в мировую, используя функцию `GetReferencePlaneTransform`, и устанавливает новое положение актора.
*   **`TransformReferencePlane`**: Устанавливает позицию и вращение `BP_ReferencePlane` в соответствие с положением центрального тела.
*   **`GetReferencePlaneTransform`**: Возвращает `Transform` (позицию и вращение), определяющий опорную плоскость центрального тела. Используется для преобразования координат.

#### Функции управления состоянием
*   **`StartSpaceBody`**: Запускает работу тела (вызывается из менеджера акторов). В основном активирует цепочку событий в `ExecutionSequence_1`.
*   **`SetOrbitVisibility`**: Включает или выключает видимость линии орбиты.
*   **`SetBodyProperty`**: Устанавливает статические параметры тела (`BodyName`, `BodyClass`, `Radius`).
*   **`SetRadius`**: Устанавливает радиус сферы коллизий (`Sphere`) и изменяет масштаб вспомогательных визуальных элементов (`NorthPoint`).
*   **`SetStandardGravitationalParameter`**: Устанавливает гравитационный параметр тела.

#### Вспомогательные функции (Pure Functions)
*   **`GetSpeed`**: Рассчитывает текущую орбитальную скорость тела.
*   **`Get Distance to Pown`**: Возвращает расстояние от тела до игрока (в сантиметрах).
*   **`GetMovingDirection`**: Возвращает нормализованный вектор направления движения тела.
*   **`GetRadius`**: Возвращает текущий радиус тела.
*   **`GetSpaceBodyProperty`**: Возвращает структуру со всеми статическими свойствами тела.
*   **`GetStandardGravitationalParameter`**: Возвращает гравитационный параметр тела.

#### Функции интерфейса (UI/Widget)
*   **`SetupHUD`**: Находит виджет-компонент (`Widget`), получает из него пользовательский виджет (`UserWidget`) и кастит (преобразует) его к типу `W_SpaceBody`. Затем сохраняет эту ссылку в переменную `SpaceBodyWidget`.
*   **`UpdateWidgetStaticInfo`**: Обновляет статическую информацию на виджете (имя, класс тела).
*   **`UpdateWidgetDynamicInfo`**: Обновляет динамическую информацию на виджете (скорость, расстояние до игрока, направление движения).

## 5. Логика взаимодействия компонентов

1.  **Орбитальное движение:** Ядром является `KeplerOrbitAnimationComponent`, который по шагам времени пересчитывает положение тела. `UpdateLocation` берет эти данные и транслирует их в игровой мир.
2.  **Визуализация орбиты:** При настройке создается отдельный актор `BP_OrbitPlaneDrawer`. Он получает параметры орбиты (векторы, апоцентр, перицентр) из `KeplerOrbitAnimationComponent` и визуализирует их.
3.  **Интерфейс:** Виджет `W_SpaceBody` является "глазами" системы. Он подписывается на обновления от `BP_BaseSpaceBody` и отображает всю важную информацию, делая взаимодействие с телом наглядным для игрока.

---

## 6. Расширение и использование

Чтобы создать новый тип небесного тела (например, `BP_GasGiant` или `BP_Asteroid`), вам нужно:

1.  Создать дочерний Blueprint от `BP_BaseSpaceBody`.
2.  В дочернем классе переопределить переменные (радиус, имя, класс, гравитационный параметр).
3.  При необходимости переопределить некоторые функции (например, `StartSpaceBody` для добавления специфической логики при запуске).
4.  Добавить свою уникальную визуальную модель в качестве дочернего компонента к `RootComponent` или `Sphere`.

Этот базовый класс предоставляет мощный фундамент, избавляя от необходимости писать сложную орбитальную механику для каждого нового объекта в игре.
